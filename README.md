# NTFSChecker

Инструмент для аудита прав доступа к файлам и папкам на NTFS-шарах: рекурсивно обходит каталог,
сравнивает ACL каждого элемента с ACL корневого каталога и показывает, где права «поехали» —
в виде цветного дерева и выгрузки в Excel.

## Зачем это нужно

На файловом сервере («Общие данные», «Отдел кадров», «Бухгалтерия» и т. п.) права обычно задаются
один раз на корень, а дальше наследуются вниз. Рано или поздно кто-то открывает свойства отдельной
папки, снимает наследование и выдаёт доступ «на минутку». Через год в шаре десятки тысяч каталогов,
и найти в них лишние или забытые записи через «Свойства → Безопасность» невозможно.

NTFSChecker делает это за один проход: берёт корень за эталон и подсвечивает каждый каталог и файл,
где состав прав отличается. На выходе — понятная картина «где сломали наследование и кому что дали»
и таблица для отчёта.

## Что делает

1. Выбираете каталог (локальный, сетевой `\\server\share` или смонтированный диск).
2. Жмёте «Проверить» — программа рекурсивно обходит всё дерево и читает ACL.
3. На вкладке «Статистика» смотрите результат: дерево каталогов, у каждой записи доступа свой цвет.
4. «Меню → Экспорт в Excel» — отчёт с легендой. По умолчанию только расхождения, в настройках можно
   включить выгрузку всего дерева.

Эталон — **корневой каталог**, а не родительская папка: так видно любое отклонение от того, как шара
задумана изначально, даже если права аккуратно менялись каскадом.

## Легенда цветов

| Цвет | Значение |
|------|----------|
| чёрный | запись доступа совпадает с корневой |
| (настраиваемый) «Отличия в правах» | пользователь/группа есть и в корне, и здесь, но набор прав или тип (разрешить/запретить) другой |
| (настраиваемый) «Нет у корневого каталога» | доступ выдан только здесь — в корне такой записи нет |
| (настраиваемый) «Нет у дочернего каталога» | в корне запись есть, а здесь её сняли |

Кроме того, для каждой записи подтягивается описание пользователя или группы: локальные учётные
записи — с машины, доменные — из Active Directory по LDAP.

## Настройки

* `Домен` — LDAP-путь для получения описаний доменных учётных записей (например `LDAP://example.local`).
* `Цвета` — цвета подсветки трёх типов расхождений.
* `Экспорт`:
  * `Экспортировать все` — в отчёт попадает всё дерево, а не только различия;
  * `Игнорировать неопределённые права` — пропускать записи с нераспознанными битовыми масками
    (частый мусор от старых утилит и миграций).

Настройки хранятся в `appsettings.json` рядом с исполняемым файлом.

## Платформы

* **Windows** — полная поддержка: NTFS ACL, `Allow`/`Deny`, локальные и доменные пользователи и группы,
  определение имени сервера для сетевых путей (`WNetGetUniversalName`).
* **Linux** — версия для просмотра ACL на смонтированных SMB/NTFS-шарах; ACL читаются через `getfacl`,
  описания учётных записей — только локальные.

## Сборка и запуск

Нужен .NET 8 SDK.

```
dotnet build NTFSChecker/NTFSChecker.AvaloniaUI/NTFSChecker.AvaloniaUI.csproj
dotnet run --project NTFSChecker/NTFSChecker.AvaloniaUI/NTFSChecker.AvaloniaUI.csproj
```

Можно открыть `NTFSChecker/NTFSChecker.sln` в Rider или Visual Studio. Вне Windows собирайте именно
проект `AvaloniaUI`: старый WinForms-проект (.NET Framework 4.7.2) в состав решения входит и на Linux
ломает сборку всего решения. Отчёты складываются в папку `Reports` рядом с приложением.

## Структура решения

| Проект | Назначение |
|--------|-----------|
| `NTFSChecker.Core` | модели, интерфейсы, экспорт в Excel (EPPlus), настройки |
| `NTFSChecker.Windows` | чтение NTFS ACL, локальные/доменные учётные записи, сетевые пути |
| `NTFSChecker.Linux` | чтение POSIX ACL через `getfacl` |
| `NTFSChecker.AvaloniaUI` | актуальный кроссплатформенный интерфейс (Avalonia + MVVM) |
| `NTFSChecker.WinForms` | старая версия интерфейса на .NET Framework 4.7.2, оставлена для истории |

## Ограничения

* Сравнение идёт только с корнем выбранного каталога; цепочка наследования не разворачивается.
* Нет кэширования — каждый запуск читает ACL заново, на больших деревьях это долго.
* Экспорт в Excel сразу открывает файл, поэтому на машине должен быть установлен Excel.
